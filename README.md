# Pure Frontend Timebox

一个纯前端的时间管理应用，无需服务器或构建工具，直接在浏览器中运行。

## 特性

- ✅ 纯HTML/CSS/JavaScript实现
- ✅ 无需服务器或构建工具
- ✅ 本地数据持久化 (使用localStorage)
- ✅ 响应式设计
- ✅ 任务管理功能 (添加、编辑、删除、标记完成)
- ✅ 任务优先级设置
- ✅ 时间预估
- ✅ 统计信息展示
- ✅ 即时可用，双击即可在浏览器打开

## 快速开始

只需双击 `index.html` 文件即可在浏览器中打开应用。

## 技术栈

- HTML5
- CSS3 (原生样式，无框架)
- Vanilla JavaScript (ES6+)
- localStorage (数据持久化)

## 功能说明

1. **任务管理**：添加、删除、标记完成/未完成
2. **优先级设置**：高、中、低三个优先级
3. **时间预估**：为每个任务预估所需时间
4. **实时统计**：显示任务总数、待处理、已完成及平均时间
5. **数据持久化**：所有数据保存在浏览器本地存储中

## 设计理念

这个应用专注于：
- 极简主义设计
- 最小化资源使用
- 快速加载和响应
- 无需外部依赖
- 跨浏览器兼容

# Timebox AI

一个纯前端时间盒子 / 任务管理实验。

## 当前状态

这个项目目前已暂停维护，保留为公开作品集和时间管理工具实验记录。

它最初想把时间盒子、任务限制和更强的执行意识放到一个简单网页里。后来发现，一旦时间盒思维真的进入日常生活，很多时候并不需要一个显性工具一直提醒。

## 它想解决什么问题

当时的核心问题是：任务容易膨胀，时间容易失控，行动容易变成“想做很多”而不是“在限定时间里完成一个具体动作”。

这个项目想解决：

- 把任务放进明确时间框
- 让每个任务带有时间估计
- 用优先级和状态帮助筛选任务
- 通过统计反馈看到待处理和已完成情况
- 不依赖服务端，打开网页即可使用

它背后的思路接近时间盒管理：先限制时间，再在限制里行动。

## 设计思路

设计上刻意保持简单：

- 纯 HTML / CSS / JavaScript
- 本地 localStorage 保存数据
- 不需要后端
- 不需要安装复杂依赖
- 双击 `index.html` 就能运行

它更像一个“随手可用的时间盒草稿本”，而不是完整的项目管理系统。

## 后来的反思

这个项目的思路仍然有价值，但工具本身不是关键。

真正重要的是时间盒背后的行动原则：限定时间、降低任务颗粒度、先开始、到点复盘。这个思维一旦成为习惯，就不一定需要一个网页来显性化。

而且电脑网页并不总是最方便的执行入口。很多现实行动发生在手机、纸上、聊天窗口、日程软件，或者干脆就是立刻开始做。

## 是否继续维护

暂不维护。

后续如果重新启动，可能不会继续做成独立网页，而会更贴近真实日常：

- 和现有日程 / 提醒工具结合
- 更轻量的快速开始入口
- 更少字段
- 更强的行动提醒和复盘

## 技术栈

项目是纯前端实现，主要使用 HTML、CSS、JavaScript 和 localStorage。

## 作品集说明

这个仓库展示的是一次时间管理工具实验。它现在不是主力工具，但记录了从“需要工具约束自己”到“把时间盒思维内化为行动习惯”的转变。
